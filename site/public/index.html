Said plainly

What it does not do.

You trust us with the key
Each key is encrypted on its own and no API returns it, but the hosted service decrypts it to forward a call. Start with a test key.
It only sees calls that pass through
A key in a .env file, a direct database connection or another tool is never seen.
The map is a reviewed list
A call it does not know to be irreversible goes through. Add hold rules for anything else.
The guard is a seatbelt, not a sandbox
It matches a map of commands. For a hard stop, give the agent a token, not the real key.
Budget seal caps only its own calls
Not your cloud bill, keys used directly or other tools. One call can pass the cap by its own cost.
Security is self-assessed
Checked by us against OWASP ASVS 5.0. No SOC 2, no external audit yet.
