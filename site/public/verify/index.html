What is checked

  
    
    
  1. The checkpoint's Ed25519 signature verifies under this log's verifier key, and its size equals the bundle's tree size.
    2. 
    
  2. The SHA-256 leaf hash of the canonical entry matches the bundle.
    3. 
    
  3. The inclusion proof walks from that leaf to the checkpoint's root (RFC 9162).
    4. 
    
  4. If the bundle carries an opening, it matches the entry's submitter commitment.

A broker receipt (entry source: "broker") was written by the broker itself for a decision it made; no agent or API key holder can write one. Any other receipt is what an agent reported, with a receipts API key. To check offline, use sdk/receipts.mjs verify bundle.json --key <verifier key> from the repository. See the docs.
