# Test vectors for sdk/shellmap.mjs. One command per line.
#   HOLD <rule> | <command>   the command must be held, and one of the hits must be <rule>
#   PASS | <command>          the command must not be held at all
#   "@ps <command>" is read as PowerShell (the Claude Code PowerShell tool).
#   GAP | <command>           a documented limit: the guard does not see this (must pass today; docs list these)
# "⏎" stands for a newline inside a command. The working directory in the tests is /home/u/proj (the project root),
# the home directory is /home/u. package.json of the project has the scripts clean, db:reset, build, test, deploy.
